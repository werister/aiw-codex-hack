# Better-Skills zum Weitergeben

Drei vollständige Skills mit ihren Originaldateien und vorhandenen Lizenzen.

| Skill | Zweck | Inhalt |
| --- | --- | --- |
| Better | Eine Aufgabe oder einen Prompt fundierter formulieren, ohne den Umfang zu vergrößern. | [SKILL.md](better/SKILL.md) |
| Better New | Neue Produktideen anhand des bestehenden Projekts und verfügbarer Belege finden. | [SKILL.md](better-new/SKILL.md) |
| Better Function | Eine bestehende Funktion oder einen Nutzerablauf gezielt verbessern. | [SKILL.md](better-function/SKILL.md) |

Der zweite Skill heißt **Better New** (`better-new`); „Better Neo“ ist hier als dieser Skill verstanden.

## Verwenden

Die drei Unterordner vollständig in den eigenen Codex-Skill-Ordner `~/.codex/skills/` kopieren. Die Dateien unter `agents/` und die vorhandenen `LICENSE`-Dateien gehören dazu.

Beispielaufrufe im passenden Projekt:

- `$better Formuliere diese Aufgabe fundierter: …`
- `$better-new Finde neue Produktchancen für dieses Projekt.`
- `$better-function Verbessere den Datei-Upload.`

Zum Lesen reichen die oben verlinkten `SKILL.md`-Dateien. Zum Weitergeben den gesamten Ordner `shared-skills` kopieren.
