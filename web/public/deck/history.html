Measured comparisons

These cards show the values recorded for each comparison. The note and test group matter: scores from different test rows are not one continuous trend.

Percentage points: when both values are percentages, subtract the before percentage from the after percentage. For example, a change from 80% to 82% is +2 percentage points. That is different from saying it improved by 2%.
